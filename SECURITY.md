# Общие данные комнаты

Это статическое расширение без сервера, базы SQLite, паролей и токенов приложения. GitHub Pages отдаёт файлы; сохранение и синхронизация выполняются официальным SDK через `OBR.room.getMetadata`, `setMetadata` и `onMetadataChange`.

Room metadata не является приватным хранилищем. Любой участник комнаты и другие расширения с доступом к метаданным потенциально могут прочитать или изменить листы. Выбор владельца по ID пользователя и интерфейс ведущего организуют данные, но не являются авторизацией. Приложение не обещает защиты от участников комнаты или недоверенных расширений. Декоративный штамп «Конфиденциально» сохранён из прототипа и не обозначает техническую приватность.

Формат листа содержит только здоровье, стресс, отмеченные симптомы, инвентарь, ФИО, записи и задачи. Личная тайна, холод, заражение и галлюцинации отсутствуют в UI и схеме. Дополнительные поля отвергаются проверкой формата; старая SQLite БД и старые локальные листы не импортируются. Пользователь может сам вписать секрет в обычную заметку — это сделает его общим. Ведите секреты отдельно.

На опубликованный GitHub Pages не отправляются игровые листы: они записываются в комнату Owlbear через SDK. В метаданные также попадают ID/имя владельца, профессия, версия формата и случайная ревизия. Скачанный JSON-черновик содержит обычные игровые записи; не публикуйте его без согласия игроков.

Ключи разных владельцев и профессий независимы. Перед записью сверяется ревизия, но серверной блокировки/атомарного compare-and-swap в SDK нет. Строго одновременная запись в один ключ может перезаписать предыдущую. Это не гарантированное разрешение конфликтов; не редактируйте один лист одновременно. Ошибки SDK и неизвестные форматы не переводятся молча в локальный режим и не выдаются за успешное сохранение.

Вне Owlbear доступна явно обозначенная локальная проба: её данные хранятся только в браузере и не переходят в комнату. Эта проба использует новый ключ localStorage без автоматического переноса секретов старой версии.

SDK 3.1.0 зависит от `uuid@9`. `npm audit` сообщает moderate advisory GHSA-w5hq-g745-h8pq о v3/v5/v6 с предоставленным буфером и зависимом SDK. Проверенные MessageBus/GenericItemBuilder SDK вызывают v4 без буфера; принудительная подмена зависимости SDK не выполнялась. Следите за официальным обновлением SDK и повторяйте аудит зависимостей.
